The problem

Every mining pool today has an operator. That operator holds your earnings, decides which transactions go in a block, and can be pressured or shut down.

A pool without an operator is not a new idea. P2Pool tried it. Commons Pool is a different attempt at the same goal: no custodian, no coordinator, and no parallel chain.

How it works

Miners keep template selection. The pool does not pick transactions for you.

When the pool finds a block, the coinbase already pays miner addresses from a shared snapshot of work. No pool wallet. No withdrawal.

Peers agree on that snapshot at checkpoints instead of running a second blockchain. Between checkpoints, every coinbase is built from the last finalized set.

A BTCDecoded project

Shipped by BTCDecoded. Runs on Bitcoin Commons, not Bitcoin Core. Consensus is specified in the Orange Paper, so the node layer is not a single implementation.
